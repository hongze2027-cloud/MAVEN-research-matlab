# MAVEN Spacecraft Data & Convective Electric Field Analysis

This repository contains the matlab code and visual analysis for processing NASA MAVEN spacecraft magnetometer (MAG) and ion plasma (STATIC) dataset moments.

**Repository Contents**

* **`Plasma_Plots_description.pdf`**: A document containing the complete set of MATLAB-generated figures (Figures 1–29)—including spatial heatmaps, 3D orbit trajectories, and time-series distributions—along with concise physical descriptions for each plot.
* **`Matlab.txt`**: The complete MATLAB source code used to downsample raw MAVEN data, align cross-instrument time grids, calculate vector fields ($E = -V \times B$), filter unphysical outliers, and produce all output visualizations.
